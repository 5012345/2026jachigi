# 자치기 한판!

우리 전통 놀이 **자치기**를 웹 게임으로 옮긴 수업용 앱입니다.
어미자(긴 막대)로 새끼자(짧은 막대)를 띄워 올린 뒤 힘껏 쳐서 멀리 날리고, 날아간 거리를 **자(1자 = 50cm)** 단위로 잽니다.

- 설치·로그인·서버 없이 `index.html` 파일 하나로 동작합니다.
- 전자칠판, 크롬북, 태블릿, PC에서 터치·마우스·스페이스바로 할 수 있습니다.

## 놀이 방법

1. **방향 정하기**: 좌우로 움직이는 화살표가 수비수 사이 빈 곳을 가리킬 때 탭합니다.
2. **새끼자 띄우기**: 왼쪽 게이지가 초록 칸에 왔을 때 탭합니다.
3. **힘껏 치기**: 꾹 눌러 힘을 모으고, 새끼자가 동그라미 안에 들어오면 손을 뗍니다.

친 뒤에는 3인칭 화면으로 바뀌고, 수비수가 새끼자를 잡으면 **아웃**입니다. 땅에 떨어지면 어미자를 한 번씩 뒤집으며 거리를 잽니다.

## 경기 규칙

- 참가 인원은 **1~20명**(1번 ~ N번)이고, 한 사람당 **기회는 3번**입니다. 헛스윙과 아웃도 기회 1번으로 셉니다.
- 한 사람의 기회 3번이 끝날 때마다 **현재 순위표**가 나옵니다.
- 순위는 세 기회의 거리 합계로 정하고, 합계가 같으면 가장 멀리 친 한 번의 기록이 큰 사람이 앞섭니다.
- 결석한 학생은 순위표에서 **건너뛰기**를 누릅니다.
- **경기 끝내기**는 실수를 막기 위해 두 번 눌러야 합니다.
- 난이도는 쉬움(수비 3명), 보통(수비 4명), 어려움(수비 5명) 세 가지입니다.

## 기록 저장

기록은 브라우저의 localStorage에 저장됩니다. 그래서 새로고침하거나 창을 닫아도 첫 화면의 **이어하기**로 계속할 수 있습니다.
같은 기기, 같은 브라우저에서만 이어집니다. 수업 중에는 전자칠판 한 대에서 계속 진행하세요.

## GitHub Pages로 배포하기

1. 이 폴더의 파일(`index.html`, `README.md`, `.nojekyll`)을 저장소 맨 위(루트)에 올립니다.
2. 저장소의 **Settings → Pages**에서 **Source**를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 정하고 저장합니다.
3. 1~2분 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 접속합니다.

## 로컬에서 실행하기

`index.html`을 브라우저로 바로 열면 됩니다.
글꼴(Jua)은 Google Fonts에서 불러오므로, 인터넷에 연결되어 있지 않으면 기본 글꼴로 표시됩니다.
